==Recording Replayframes(contains one or more commands and a timestamp).==
Format as described in BWrepActions.cpp from RExplorer/BWChart:

<buffer>           ::= {<time param><block size>{<actions>}}
<time param>       ::= 4 byte time value indicating offset from beginning of games (=time)
<block size>       ::= 1 byte size of all actions in that time tick
<action>           ::= <player id><order type><order param list>
<player id>        ::= 1 byte player id found in the header in section 1
<order type>       ::= 1 byte id of the type of order
<order param list> ::= number, format and meaning determined by order type;

When a command for a new frame is recorded, or the old frame is full, a new frame-entry is created. This creation function first writes the size of the old frame at byte 4 of the old frame. Then it creates a new frame beginning with the timestamp.
I hook where it writes the size of the old frame, because at that time the beginning address of the old frame and the size of the old frame are both known.
The address where it writes is 4CDA1C.
Because the size of the command I want to replace is smaller then 5 bytes(required for call/jmp patch) I insert a short jump to free memory direcly before the function. In this mini cave I add the call to my hook function, the original command and a jump back to the function.

==Saving a replay==
push 1;
mov EAX,PointerToReplayName
Call $4DF6A0;

PointerToReplayName is a 0 terminated string which contains the replayname relative to the replay basedirectory but not including the fileextension.
