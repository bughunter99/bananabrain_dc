zLoader v1.0.0.1
Dll hack loader for Starcraft/Brood War
Made by Zynastor (zynastor@hotmail.com)
http://www.bwhacks.com

Instructions:
 - Extract to a directory.
 - Place all the dll hack files in the same directory as zLoader.exe and zLoader.snp.
 - Run zLoader.exe while starcraft is open or closed, if closed zLoader will start starcraft for you.
 - Start playing.

Notes:
 - Most hacks will require you to run zLoader after you have entered battle.net because of
   the anti-hack protection by blizzard.
